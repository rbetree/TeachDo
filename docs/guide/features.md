# 功能介绍

TeachDo 以教师备课主链路为中心，将内容生成、知识库增强与编辑导出串联到同一个工作流中。

## 备课主链路

1. 输入主题或课程目标，生成课程大纲。
2. 在大纲基础上继续生成教案内容。
3. 进一步生成 PPT 内容并预览页面。
4. 跳转独立编辑器完成精修和最终导出。

![TeachDo 工作流预览](/images/05-outline-compare.png)

## 大纲生成

- 通过 SSE 流式返回大纲内容，生成反馈更即时。
- 支持保存当前结果，便于后续继续补全和调整。
- 支持版本对比，适合课堂方案的迭代优化。

![大纲生成页面](/images/02-outline.png)

## 教案生成

- 基于已确认的大纲继续生成教案，减少重复输入。
- 内容生成过程与工作台上下文保持一致。
- 支持导出标准 `.docx`，方便教师继续线下编辑和分发。

![教案生成页面](/images/03-lesson.png)

## PPT 生成与预览

- 支持选择模板并按页增量生成 PPT 内容。
- 工作台负责只读预览，降低误操作风险。
- 生成产物默认以 Markdown 沉淀，便于后续编辑器继续处理。

![PPT 生成预览页面](/images/06-ppt-preview.png)

## 助教问答

- 结合教学资料、知识库检索结果和已选文件上下文进行问答。
- 适合快速追问重点知识点、活动设计和课堂讲解方式。
- 与大纲、教案、PPT 链路共享同一份课程上下文。

![助教问答页面](/images/04-assistant.png)

## 知识库增强

- 支持上传教学素材并进行向量化检索。
- 支持将生成产物重新沉淀到知识库中，形成可复用资产。
- 在生成阶段可按文件范围选择引用上下文，提升可控性。

## 独立编辑器与导出

- 工作台中的 PPT 区域以预览和流程推进为主。
- 最终编辑、样式调整和导出在独立编辑器中完成。
- 支持导出 PPTX，并通过产物 API 进行持久化管理。

![PPT 编辑器页面](/images/09-ppt-editor.png)

- 便于在不同模型、模板和生成策略之间切换。
