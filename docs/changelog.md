# 更新日志

本页基于 `doc/CHANGES.md` 整理，仅记录会影响对接、使用和迁移的关键变更。

## 2026-03-20

- 文档口径统一：维护文档默认以代码实现为事实来源，历史与 legacy 文档仅用于补充边界说明，避免口径漂移。
- API 命名对齐：新增推荐端点 `POST /tools/outline` 与 `POST /tools/ppt`。
- 兼容策略保留：继续兼容历史别名 `POST /tools/aippt_outline_unified` 与 `POST /tools/aippt`，便于渐进迁移。
- 前端对接更新：`services` 层与冒烟脚本默认改用新端点，旧端点仍可继续使用。
- 文档与结构清理：移除未引用旧组件与误导性文案，并同步更新 `Slide JSON` 结构文档与相关路径引用。
